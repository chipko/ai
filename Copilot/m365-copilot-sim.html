JSONL format
{"type":"scene","title":"…","section":"…","slide":"47"}
{"type":"model","value":"Think Deeper"}
{"type":"prompt","text":"…","context":["Paper.docx","Pack.xlsx",
  {"name":"Budget queries","kind":"email"}]}   (files attached to this prompt, shown as chips)
{"type":"think","steps":["Reading Paper.docx",{"text":"Comparing","ms":2500}]}
{"type":"response","markdown":"…[1]","refs":[{"title":"Paper.docx","kind":"docx","meta":"You attached this"}],"followups":["…"],"files":[{"name":"Deck.pptx","meta":"8 slides"}]}
{"type":"caption","text":"…","ms":4000}
Any script command works as {"type":"newchat"}, {"type":"pause","value":1500} …
A file with several "scene" lines imports as several scenes.
Script cheat sheet
> prompt text          type it into the box and send
~ thinking step        shown while Copilot works (add {2000} for ms)
~= Thought for 20s     label once the thinking collapses
< response…           Markdown until the next command line:
                       ## heading, **bold**, - bullets, 1. lists,
                       | tables |, ```code```, [1] citations
^ Title | kind | meta  a reference (docx xlsx pptx pdf email
                       meeting teams web loop)
? follow-up            a suggestion chip under the answer
@file Name.pptx | 8 slides   a file Copilot made

@model Think Deeper    open the model picker and choose
@mode off / @mode on   the Work IQ toggle (crossed out when off)
@attach A.docx; B.xlsx pick files with the + button
@type text / @send     type without sending, then send
@newchat               start a new chat
@caption Text | 4000   lower-third caption (@caption clears)
@highlight model | Label    ring + label (@unhighlight)
   targets: model work web plus send composer notebooks
   newchat chips prompts last lastprompt refs file
@click target          move the pointer and click
@pause 1500            wait (ms)
@scroll prompt|end     scroll the conversation
@save Title            save the last prompt to the gallery
@gallery Suggested|Saved|Team   open / switch tab
@share                 share the newest saved prompt
@close                 close a dialog
@notebooks             open Notebooks
@create Month End      create a notebook
@refs A.xlsx; B.docx   add references to it
@instructions text     type the notebook instructions
@instant … @live       set up earlier turns with no animation
@theme dark|light      switch mid-scene
@tooltips on|off       tooltips when the pointer rests on a control
@tip plus | Add content   show one tooltip
@snapshot name         save the current frame as a PNG

Record for PowerPoint

Records just the Copilot window (no browser bars) to MP4: title card → the scene → end card, hands-free. Choose this tab when the browser asks. Esc stops early. Every frame is drawn at exactly the video size and encoded at a constant frame rate, and the finished file is decoded and checked against the screen before it is saved.

Tips

• Open this file directly in Chrome or Edge. Previews and embedded frames block screen capture.
• Make the window large (F11 helps). The clip is scaled to the video size, so a bigger window gives a sharper clip.
• Recording a section downloads one file per scene. If Chrome asks to allow multiple downloads, choose Allow.
• Files are rebuilt as standard MP4 (H.264) without re-encoding, so PowerPoint accepts them: Insert → Video → This Device.

Snapshots

📷 Frame (or P) pauses playback and saves the Copilot window as a PNG at the video size, for example for the tour slide. The first snapshot asks to share this tab; the capture then stays open for two minutes so you can take several. In a script, @snapshot name saves a frame mid-scene; during a recording it needs no extra prompt.
